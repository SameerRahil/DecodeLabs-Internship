# Project 1: Rule-Based AI Chatbot

This is my Week 1 Artificial Intelligence project for the DecodeLabs internship.

## Description

This project is a simple rule-based chatbot built using Python. It uses predefined rules, control flow, dictionary-based response lookup, input sanitization, fallback handling, and a continuous loop to simulate basic chatbot interaction.

## Features

- Handles greetings and common user inputs
- Uses dictionary-based responses
- Supports keyword-based matching
- Sanitizes user input by handling uppercase, lowercase, spaces, and punctuation
- Provides fallback responses for unknown inputs
- Runs continuously until the user enters an exit command
- Supports exit commands like exit, quit, bye, stop, and goodbye

## Concepts Used

- Python basics
- Control flow
- If-else logic
- Dictionaries
- Loops
- Functions
- String handling
- Rule-based AI logic
